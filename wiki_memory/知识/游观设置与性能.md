# 游观设置与性能

## 公开参数

2026-10-22用户要求新增导航设置、公开各卷滚轮速度并改善顺滑度、所有文字加可调底；2026-10-23再次明确必须保持参考图的微透明纸底，不能改为偏实色圆角卡片。ViewerSettingsPanel采用原生dialog，首页及画卷导航均可打开，调整即时生效；关闭/ESC恢复有效触发点焦点，浏览器历史/Hash导航关闭弹窗。

`viewerSettings.ts`为唯一默认值、边界与存储校验入口。`guose-fanghua:viewer-settings:v2`保存在localStorage，存储禁用不影响当次操作，损坏/未知版本恢复默认。本轮未交付的v1实色草案不读取，以免旧默认覆盖用户纠正后的微透明样式。颜色只开放五种浅纸色以保留深墨对比；参数变更通过ref/props生效，不重建WebGL场景。恢复默认是可逆操作，无确认中断。

2026-10-23用户补充参考图，要求四卷画心左右留白等宽且参数公开。`sideMarginPercent`默认8%，每侧按画面宽度计，范围0—18%、步长0.5，统一用于四卷并即时持久化；旧v2记录缺字段时取8%，保持存储版本兼容。`sourceViewportLayout`把画心居中置于纸色画布内，保留原画比例和竖向取景；0%恢复宽屏铺满。调整只更新SceneRenderer视口，不重建WebGL画布。

| 范围 | 默认 | 可调范围 |
| --- | --- | --- |
| 四卷分别滚轮速度 | 全卷0.5%/100 CSS px | 0.1—2%，步长0.05 |
| 四卷分别平滑时间 | 180ms指数跟随常数 | 60—500ms |
| 四卷共用左右画心留白（每侧） | 画面宽度8% | 0—18%，步长0.5% |
| 共用纸底 | 米白#f7efdf | 米白/素纸/暖绢/浅玉/素灰 |
| 纸底峰值不透明度/留白 | 80% / 12px | 20—100% / 4—24px |
| 圆角/边框浓度 | 0px / 0% | 0—20px / 0—60% |

文字按整组设微透明纸底，正文总有底，不再依密集度才出现。正文沿用原纸绢渐变与上下柔边，默认无描边/圆角/投影，不能变成卡片；透明度只改变底，不淡化文字。紧凑控件使用比例留白；题跋序号纳入底内，正文容量随区域与留白调整，保留原字。画心小于900px或矮于400px采用横排，竖排使用固定可用文字盒，避免max-content缩盒后文字漏出纸底。横排下方候选按底部定位，防止短屏溢出；调整视口/留白不做跨画心位置动画。原画烘焙文字和印记不重绘；实体题签内层清洁纸材继续遮挡原烘焙卷名，其上叠微透明调色层。

## 滚动边界

旧100px推进1.6%，页模式输入可单次跳十几个百分点；现按CSS像素归一行/页输入，单事件限160px，连续输入积压限当前进度±6%，反向抛弃旧方向积压。时间轴seek仍允许全卷跳转，键盘原步进保留。拖拽惯性按真实时间积分，平滑采用指数跟随，系统reduce即时定位。180ms约540ms到达目标95%，不是总动画时长。

控制器只在正在跟随或播放时请求RAF，静止不空转；后台/非交互时取消RAF、停止播放并丢弃残余目标，恢复不漂移。sessionStorage保存四卷进度，不混入用户长期参数。滚轮Ctrl手势留给浏览器缩放。

## 渲染与资源

`NarrativeSpace`只分析保持比例的最大256×192（49152像素）缩略图；SceneRenderer渲染离屏target后异步读回，复用CPU缓冲。准备时可立即分析，视图停止变化180ms再更新正文位置。代际隔离阻止context loss/dispose旧异步结果回写，新尺寸/桶变化重新采样。候选纸白与边缘启发式无法保证主体完全避让。

源显隐前后0.012进度内的临近图层提前取纹理，占至多一个后台槽；共四并发，当前可见优先。未来纹理不参加当前ready门槛、不提前显示，未来失败不报告当前缺画；真实当前失败仍可恢复。保留作者相机、原矩阵、时间、显隐及画面素材。

相同源时间复用动画/显隐结果，预取相机复用，恒等scene关闭重复世界矩阵遍历；每个源网格/独立动作仍显式更新自身世界矩阵。shader失败停止RAF并锁住首帧，迟到纹理不清错误，恢复重建renderer。诊断仅在canvas.dataset，不把技术指标写进产品流程。

## 验证入口与边界

scroll-input测试覆盖单位、限幅、反向及15/30/60/120/144Hz时间积分；render-performance测试执行实际纹理队列/失败逻辑及缩略图上限，GPU用stub。viewer-settings在真实生产Chromium上验收四卷8%对称边距、10%即时调整与持久化、1100—1672px桌面布局、空闲及后台行为；完整结果见`reports/viewer-settings/validation.json`。该工程当前最小桌面画布宽度为1100px，不把小屏验收作为此产品目标。new-runtime遍历全部节点与正文，new-journey覆盖入口、慢资源/故障/取消。

浏览器在本机Chromium执行；CPU上限、无空闲重绘、原数据完整不能证明所有设备持续60FPS。源原件不在仓库，原DOCX哈希核验与依已跟踪提取记录的正文完整性核验须区分。
