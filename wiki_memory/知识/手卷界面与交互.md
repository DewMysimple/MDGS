# 手卷界面与交互

## 当前2.0首页、入卷与正文（2026-10-23局部复核）

当前首页采用同一参考相机投影的连续有深度relief，加实体轴杆、曲面绢纸与主要器物体积；不是下述前轮独立建模书房。等比cover加3.5%出血铺满视口，裁边而不拉伸；横屏题签按投影限界，竖屏四个HTML按钮排2×2。两片连续卷曲薄烟、错峰慢落单瓣、微尘与局部枝叶变化遵循同一轻风；静置环境30Hz，off/reduce/hidden/离场暂停。参考身份和shader编译/首绘门控保留，错误不能解锁入口。

useStudyJourney仍负责Hash/历史、按卷sessionStorage进度、取消与前台最低4000ms加载门。加载核心是真实2,415顶点双面纸绕轴，木杆分离、弧度随之变化；画心来自2.0实际WebGL首帧，等比cover整个绢纸，解析法线、共享背面与接触影减轻开销。资源、目标首帧、加载画心和最低时长共同放行，每次选择均执行仪式；reduce保留闭合/展开状态及时间。

新源不运行旧CalligraphyLayer/canonical题字。25段DOCX原文按6/6/6/7保留，newNarrative/narrativeTrack依作者时钟和当前15/7/9/9节点显示，楷体本地交付；留白分析为启发式，不能代替主体遮挡审阅。卷末真实进度1时退出正文并落印。配乐为用户点击后启用的本地原创合成古筝意境拨弦，非真人录音；返回/隐藏暂停，释放清理媒体。

2.0只给实图审核的24个独立原生图层添加局部轻动，章二/四组合层不入名单；80枚按节点锚定的独立单瓣最多同时两枚加一获准原层，人物/建筑不追加矩阵delta。作者原有动画及25个shapeKey另行保留。真实生产报告已测桌面/手机80次节点、166段正文、13组首页、8组入卷和编译中取消；细节与未测设备边界见[本轮验收](../../reports/peony-2.0/README.md)。
