# 手卷界面与交互

## 当前结构与修改入口

`App.tsx` 保留章节/分镜/卷末/进度业务；`ScrollOrnaments.tsx` 的 ScrollRoller、BrocadeBorder、ExhibitionAtmosphere 构成共用形制；外部装裱固定，画心独立游观。`styles.css` 导入主题tokens、阅读面板、手卷CSS；先改 `styles/exhibition-theme.css` 的颜色/字体/尺寸变量，再按需改 handscroll.css。当前是桌面版，body最小宽960px，主验收1440×900、1680×945；不增加手机菜单等新范围。

公共纹样在 `public/ui/`，是真实SVG；案台为简化CSS木纹，画作仍用用户原场景，不把概念图贴成整张背景。`reports/handscroll-ui-review.md` 与 handscroll-* 截图对应现版；`viewport-layout.md` 的77%近满屏布局及早期browser-validation属于历史阶段。

## 游观数据流

manifest经prepareScene给出真实stops → ScrollViewport回传 → App只缓存轻量id/stops → useScrollController维护target/progress → SceneRenderer.setProgress更新同一相机。四卷15/7/9/9个节点不能硬编码为参考图示例数字。切章只改变chapterId并stop，不刷新页面；hook模块Map保存本页面会话进度，刷新后重置。

滚轮与拖拽由ScrollViewport接管，手动输入停止自动展卷。host必须真实100%宽高，ResizeObserver更新canvas与相机aspect；不以CSS强拉伸画面。装裱/卷轴/题字及背景必须pointer-events:none，避免覆盖指针捕获。Grid使用minmax(0,1fr)，防止旧canvas内在宽度撑住窗口缩小后的布局。

维护以下修复：上一/下一景比较容差0.002，避免跳过末景；进度条保留onInput与Home/End等显式键盘处理；画卷Space处理排除button/input等目标，保证卷末按钮原生键盘行为。自动展卷隐藏标签页暂停，减少动效偏好使用即时seek。来源：App、ScrollViewport、hook。

## 卷内题字、声音与文化

`annotations.ts` 为四卷管理内容/字体字号/世界锚点/宽高/印章/所属分镜/显示区间；仅二卷0–.055、三卷0–.045启用，避免覆盖一/四卷密集画面及原图文字。CalligraphyLayer用CSS3DRenderer和WebGL同一相机，HTML writing-mode:vertical-rl，随世界位置移动并淡出，不是固定大文字面板。CSS自定义变量必须style.setProperty，直接Object.assign('--变量')会导致字号回退16px。

印章为中性“牡丹”展陈标记，assetUrl可替换；不伪造历史印文。`chapters.ts` 管正文、总序、题跋，文化内容按用户原文，非独立史学定论。CulturePanel打开时停播、Escape关闭、焦点还原。AudioController为用户点击后启用的本地合成五声音阶，并非录制古琴音轨；关闭会释放AudioContext。
