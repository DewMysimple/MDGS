# 旁白

用户指定音色 `Chinese_gravelly_storyteller_nv1`，按 `reports/四卷旁白内容稿.md` 原稿合成四条连续章节音频，共45句，章节句数为15/12/9/9。中国区官方T2A端点使用 Bearer API key；生成脚本从环境变量读取密钥，不在源码、清单或日志中保存密钥。音频使用 `speech-2.8-hd`、32kHz单声道MP3、语速1、音高0、质量归一化；同场景句间停0.32秒、换场停0.55秒。不添加情绪或效果标签。各卷MP3时长约94.0、76.9、55.7、58.1秒。MiniMax逐句时间戳已转换为SRT。

`NarrationController`在每卷控制栏提供用户主动播放/暂停，换卷、失活或离开展厅时停止；旁白播放时配乐渐降约6dB，仅解读面板触发原有提示音。原始声音样本未提交。

MiniMax中国区同步接口依据[官方T2A文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)；脚本按该接口使用Bearer API key。

验证：`node --check scripts/generate-minimax-narration.mjs`；`ffprobe`确认四条均为MP3/32000Hz/单声道；45条SRT与清单逐句一致；`tsc -b`通过，`npx vite build --configLoader runner`成功（1657 modules）。默认配置打包器在受限环境读取上级目录时报Access denied。尚未人工试听或逐种设备验证播放器。
