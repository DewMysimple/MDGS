# 四卷对称留白与离线发行

## 目标与结果

用户给出画卷参考并要求左右等距留白、间距参数公开；需要把修改打包为含浏览器内核的Windows EXE，并同时提供ZIP和解压文件夹。按参考图估读默认每侧8%，这项数值为实现选择；设置开放0—18%、0.5%步长，四卷共用，实时生效并持久化。视口居中保留原画比例和竖向取景，0%可回到铺满。

Windows x64便携EXE和ZIP输出至`C:\Users\Administrator\Desktop\数字牡丹赋`。ZIP为623142977B，SHA-256 `ddf2f171df8e5891a6a5c4d303417e6b1d253ba08a7739e3cffddc8c74edd653`；解压目录`数字牡丹赋-Windows-x64`内含623140130B EXE、运行说明和交付清单。EXE SHA-256 `0dac78505e929d6e6bba2fe33debf5678b1469e406bba90225b9194302f02fba`，内置Electron45/Chromium156/Node24，可离线运行。

## 关键实现

- `viewerSettings.ts`为现有v2设置增加默认8%的`sideMarginPercent`；旧v2设置缺字段时使用默认值，不清除其他设置。
- `ViewerSettingsPanel`新增“画心左右留白”滑块；App/ScrollViewport把参数传入SceneRenderer。更新标记视口dirty，不卸载画布。
- `sourceViewportLayout`将原画在相同左右边距内居中，同时保留源比例和原竖向视野。
- 生产页面截图确认参考间距与设置位置，见`reports/viewer-settings/chapter-1-desktop.png`和`settings-desktop.png`。

## 验证

- `npm run build`：TypeScript和Vite生产构建通过，1649模块。
- `npm run test:render-performance`：10项通过；`npm run test:scroll-input`：22项通过。
- `npm run test:viewer-settings`：Edge 155生产浏览器17项通过。四卷默认左右各8%；滑至10%后等宽更新，画布节点不变；重载仍为8%。覆盖1100、1280、1672px桌面布局、闲置、后台和WebGL恢复。
- `npm run export:desktop -- --output C:\Users\Administrator\Desktop\数字牡丹赋`：交付生成成功，7-Zip ZIP完整性通过，实际解压文件与清单SHA一致。
- `node scripts/validate-portable-desktop.mjs --executable <交付EXE>`：便携发行件7/7通过，含Electron/Chromium启动、离线首帧、资源与退出。
- `npm run test:desktop -- --executable dist-desktop/win-unpacked/数字牡丹赋.exe`：与便携交付资源哈希匹配的应用11/11通过，覆盖四卷交互、字体/声音/资源、下载和全屏。
