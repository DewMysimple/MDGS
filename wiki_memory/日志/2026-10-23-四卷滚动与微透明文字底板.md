# 四卷滚动与微透明文字底板

## 目标与当前选择

优化四卷进入和游观的稳定性；在导航加入“设置”，分别公开四卷滚轮速度、平滑时间，并让可见文字有可调底板。沿用现有四卷素材、源相机、动画与显隐，不改写主线正文。

用户于本轮明确要求保留原参考图的微透明纸底效果，偏实色卡片方案已经撤回。当前实现选择为渐变柔边纸绢底：默认米白 #f7efdf、峰值不透明度 0.8、留白 12px、圆角 0、边线透明度 0；文字自身保持不透明，纸底透明度由独立伪元素/背景控制，不设置文字父容器整体透明。导航、正文、卷末、加载和辅助弹层沿用统一参数，具体布局仍适配各处空间。

首页实体题签有特殊素材约束：保留干净纸材遮住原图中烘焙旧字，再叠微透明色层与真实 HTML 标题，避免两层题字重影。该遮字底材不随微透明设置露出原字。设置保存使用 v2 schema 与 guose-fanghua:viewer-settings:v2，旧版本或异常存储回退默认，不能重新带入撤回的卡片外观。

## 已实现的滚动与渲染

四卷各自默认滚轮速度为每 100 CSS 像素前进全卷 0.5%，平滑时间 180ms；面板可分别调速 0.1—2%、平滑 60—500ms。滚轮统一处理像素/行/页单位，单事件输入限制为正负 160 CSS 像素，默认最大跨度为 0.8%；目标积压限制在当前位置正负 6%，反向输入从当前位置接续，减少回头时等待旧方向余量的感觉。拖拽惯性与平滑跟随按真实时间积分，避免不同刷新率产生不同跨度。

滚动控制器静止、被入卷仪式覆盖或页面隐藏时不持续运行 RAF；会话进度按停稳/间隔保存，避免每帧同步写 sessionStorage。隐藏或离开交互阶段会暂停自动展卷、清除待追赶目标，拖拽取消/失去捕获/页面隐藏会清理惯性。

正文留白分析从全屏同步 readPixels 改为最大 256×192 缩略图、最多 49,152 像素的异步 GPU 回读，复用缓冲，游观停稳 180ms 后再采样；resize、context loss、dispose 通过尺寸检查与代际标记隔离旧读结果。缩略图只用于布局启发式，原画仍由原相机完整绘制。

预取相机复用，未前进的源时刻跳过重复动画矩阵反解；恒等 scene 不再逐帧递归更新静态纸层，源动画与轻动仍显式更新 Mesh 世界矩阵。提前预取前后方向 0.012 作者时间内将出现的隐藏层，只占一个后台下载槽，当前可见资源优先，总并发仍为 4。未来纹理不加入当前首帧就绪门槛，预取成功不会提前显示，未来失败不误报当前缺画。

shader 失败会撤销首帧就绪并停止 RAF，纹理队列与在途回调不会清除错误或重新放行；恢复操作重建渲染器。GL context loss 保留既有恢复机制，并使旧缩略图 target/buffer 与异步结果失效。

## 已执行验证与边界

集成阶段已执行并通过构建、CPU 路由与素材结构验证：npm run build、npm test、npm run validate:assets。滚动输入 CPU 验证 22 项通过；渲染性能 CPU 验证 3 组通过，包含缩略图上限、优先队列、预取显隐/门槛和 shader 失败后迟到纹理回调；新版轻动 CPU 验证 9 组、120 节点宽高比检查通过。CPU 结果不证明持续帧率或所有实际构图。

最终微透明生产构建通过设置18组、完整运行30组/80节点/180正文片段（59桌面/121手机）、入卷8组，无页面或资源错误。设置包含5种补充尺寸、四卷独立输入、最大留白、存储容错、Hash焦点、闲置停绘/后台暂停和真实WebGL丢失恢复；入卷含四入口闭半全开、至少4秒、慢纹理、cover503重试、取消旧请求及手机音频故障。设置与运行报告SHA同为8425ee6964967d199eca18286f3158aa93f714561838670c516af09e6e7d587c，源码重建核对一致；完整运行使用公开60ms加快穷举，默认180ms另验。先前偏实色候选不作最终视觉交付。

本机原始主线 DOCX 当前缺失，依赖该文件的全文源 SHA 校验本轮未重跑；主线 newNarrative 数据未修改，浏览器比对仓库已有提取记录。不得把历史 DOCX 校验记为本轮新验证。真实设备、其他浏览器、持续跨设备 FPS 和听感不在本轮已有 CPU 证据覆盖内。
