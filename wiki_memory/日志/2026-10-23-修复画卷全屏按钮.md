# 修复画卷全屏按钮

## 目标

修复 Windows 便携版画卷右上全屏按钮失效，并交付新的 ZIP 与解压文件目录。保留浏览器预览原有画卷全屏体验。

## 诊断与变更

Edge 生产预览中，按钮触发浏览器 `requestFullscreen()` 正常；Electron 45 的安全自定义协议 `mdgs://app` 中，该 API 的 Promise 一直 pending，错误被 UI 捕获后按钮看起来无反应。旧桌面验收只覆盖 F11/Escape，没有覆盖网页按钮。

新增最小 `desktop/preload.cjs` 桥接，只暴露查询/切换全屏及订阅状态；`desktop/main.cjs` 校验 IPC 来自当前应用窗口后调用 `BrowserWindow.setFullScreen`，向渲染器同步进入/退出事件。React 检测桌面桥后走原生全屏，浏览器继续调用 DOM Fullscreen API。原生全屏样式隐藏页眉和控制栏，令画卷完整占满客户端视口，并保留画内退出按钮。

首次桌面几何回归分别捕获到层叠优先级让页眉仍显示，以及旧网格行留下 114px 高空白；提高 `.peony-experience .app-shell.poetic-viewer.is-native-fullscreen` 规则优先级后，整块画卷实测到达视口边缘。上述中间失败均在最终验收前修复。
