# ADR-007 牡丹2.0源与全视口自然环境

## 选择者与替代范围

用户要求使用“牡丹2.0”四件输入替换本轮四卷，并让书房铺满网页、自然环境持续细腻。Agent在此范围内采用下面实现。当前`activeSourceEdition`为`peony-2.0-2026-10-22`，路径仍为`public/assets/new-scrolls/chapter-N`。用户同时明确授权覆盖旧`牡丹/`，因此先校验备份至忽略目录`.asset-cache/peony-pre-2.0/`再以新四件替换；`牡丹2.0/`本轮输入未改写，两输入目录不提交。四个活跃可编辑打包副本在`artwork/blender-reconstructed/`替换。旧`peony-2026-10-21`报告保留在`reports/new-scrolls`，本轮报告写`reports/peony-2.0`，不能借历史pass声明新源通过。

本决策替代ADR-006的活动源身份和contain取景；继续保留参考相机投影relief与实体轴杆/纸面结构、四个真实HTML题签、原作者时间路线、至少四秒前台闭卷加载、资源和首帧联合门控、25段原文与配乐生命周期边界。不是重新批准完整独立房间建模；较大视角自由绕行仍非现行实现。

## 已采用的实现及取舍

首页先前空边来自contain相机FOV与手机附加上移，而非容器宽高。改为保持参考比例的cover加3.5%观察出血，原图不拉伸；不同宽高比裁去边缘是该选择的明确代价。横屏题签保留真实投影并夹在可操作边界内，竖屏使用2×2清晰入口。无独立改写标题或四卷名称。

环境薄烟使用两片连续细分曲面与缓慢噪声流，替代13枚圆烟sprite；工笔色调单瓣36—55秒错峰下落及慢翻，微尘各自分相位，灯光低强度变化。首页两角枝叶只做明确局部遮罩内的微幅顶点变形，不平移桌案或建筑。静置环境最多30Hz，观察镜头仍逐帧；off/reduce/后台/离场停环境时钟和相应RAF。

四卷追加轻动需通过当前revision和实际纹理审核双门。2.0导出完成后实际打开六张纹理，核对章一17个独立花瓣、章三7个独立飘带/单灯的精确对象身份；章二/四无原生组合层获准。每正文节点最多配置两枚来自2.0首卷真实图集的独立单瓣，最多同时两瓣加一个合格原生层；随机视觉姿态不旋转重力轴，保留统一侧风。名单外的人物、宫苑和组合画面无新环境矩阵delta；源作者原有动画另行保留。

大清单JSON通过Worker读取解析，fallback在无Worker环境保留fetch/json；对象构造分片让出主线程，源矩阵轨道预分解，纹理异步解码后每帧最多提交一次GPU上传，按游观方向提前准备下一片画面，离场关闭ImageBitmap。留白分析在停滑后做低分辨率异步GPU读回并缓存，避开输入时整帧同步读回。源材质节点、scalar曲线和坐标信息已从2.0导出；`SourceMaterialEffects`以`onBeforeCompile`uniform译制入场图，不覆盖`material.opacity`，避免与环境导演相互写入。

材质完成态仅在空间区间证明alpha恒定时走uniform快路，109个图符合，17个仍保留空间mask；河流原有左右羽化不能因动画完成而变为矩形不透明边。126图/14,536 scalar/31,339 UV样本验证真实时钟与此边界。Noise为fBM，4D W映入3D；Voronoi使用对应维数/F1/Euclidean、确定性不同种子。程序噪声不宣称Blender Cycles逐像素还原。

闭卷仍以真实卷纸形变展开，2,415顶点、UV不变；共享背面几何、解析法线与保守静态包围体减轻CPU计算，接触投影网格代替额外实时shadow pass。绘画以原比例cover铺满纸面，无旧版内边距。四个2.0画心已重新从真实首帧采集，逐卷源SHA见cover-provenance，不延用旧edition身份。

源首卷25个对象具有真实shapeKey动画，已保留实际相对顶点delta、源权重轨道和GPU morphAttributes；渲染权重为源采样值减首个可见形态baseValue。25对象与追加原生轻动名单无交集，不二次叠加同对象风动。CPU逐值核对25个GPU目标及125次权重；最终原生重开分别核对源/副本75,600个整数帧权重与相对delta。本轮实际WebGL运行和节点截图见生产runtime报告。

## 已验证与恢复边界

2026-10-22至23当前未提交的协作工作树中，最终独立Blender原生八次重开通过，核对源/打包副本SHA、首个可见几何/UV、每个导出相机/矩阵样本、全部整数帧显隐、材质scalar及形态键权重/delta。网页网格149/58/79/52、纹理99/35/66/43、正文节点15/7/9/9；完整源marker17/21/18/9另保留。源帧1—3024/33—2184/1—2068/1—1800，第二卷原marker -3保留并夹到入口33。最终manifest SHA与243张WebP完整解码已由validation-assets-new.json绑定复核，不借中间导出报告替代。

CPU实际通过：正文7组、25段逐字、59个默认片段、实际prepared及作者帧两条路线的28/44/68字切片均有有效窗口；动效9组、120次节点宽高比覆盖、80逐瓣重力/侧风、未绑定主体矩阵保持及off/reduce/hidden/end；首页10尺寸、30观察边缘覆盖、四入口边界和真实生命周期。TypeScript通过。以上CPU未执行GLSL，不证明浏览器材质、实机触控或60FPS。

cover新源身份已重新采集。最后修复后实际生产浏览器通过runtime 30组（80节点/166响应式正文）、projection 13组、journey 8组、KHR编译中取消、timing 8组和当前2.0嵌套子目录。首次/缓存总时长6.662/5.769秒，加载均至少4秒；真实慢资源延长展示。四卷冷前进/暖回退各8秒，p95为7.0—13.9ms；加载截图取样仍有少量>50ms间隔，不宣称稳定60FPS。按用户最新要求已交付远程支线`codex/peony-2-home-motion`，功能提交`51dfb578`的HEAD/upstream/远程分支SHA一致，LFS fsck通过、59对象上传。支线基于原基线cd5bd9c，未融合main新增e420f0e/2dd9ccb/fa08c92，验证不代表适配其新fidelity系统。手机为浏览器模拟，实体设备、其他浏览器、物理音响和线上部署未验收。
