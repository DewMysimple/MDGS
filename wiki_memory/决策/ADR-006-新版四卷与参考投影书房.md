# ADR-006 新版四卷与参考投影书房

## 用户要求与替代范围

本轮采用“牡丹”目录提供的四份新版 Blender，覆盖四份活跃派生交付与网页四世界；源原件只读保留本机。正文取自本轮主线 DOCX。用户再次强调首页应与指定浅淡纸绢参考大致同构图、同风格。

本决策替代 ADR-005 的活动源选择与独立完整书房实现描述，ADR-005 转为历史。至少四秒闭卷展开、真实资源及首帧门控、原生入口、减少动态和返回行为继续适用并纳入本决策。较早的“不改四卷源版本”约束不能阻止本轮明确授权的新版替换；原画与 UI 分离、只读输入和普通 Git 交付约束仍适用。

## Agent采用的实现与取舍

`activeSourceEdition` 为 `peony-2026-10-21`。四世界只从 `public/assets/new-scrolls/chapter-{1..4}/` 取清单与纹理，新 sourceRevision 跳过旧 ArtDirectionLayer 与 CalligraphyLayer，不加载旧 canonical 补画题字。网页保留源世界矩阵、相机及完整源区间、标记、动画和逐帧 hide_render；新版使用原作者时间0..1同步相机、物体动画和可见性，晚到贴图不能提前显示隐藏物体。第三卷参考全景只保留在完整标记，交互9节点；第二卷实际从帧33开始，原帧1标记另存 authoredFrame。

距离归一化只适用于历史版。新第三卷后段相机虽静止，主体与显隐仍在按时间切换；按距离曾把最后三景压成极短滑块区间，末两段正文没有有效窗口。现以作者时序保留静止阅读、画面变换和第四卷快转节奏；正文另按字数分配最低阅读窗口，短句也有渐显时间，不挪动原Blender关键帧。

四份 `artwork/blender-reconstructed/chapter-N_reconstructed.blend` 已用新版打包副本替换，不增加混淆的第二套活跃交付。首卷缺图从精确原图恢复到交付，输入原件不保存。新版网格149／58／79／53，纹理99／35／66／44；首卷45首帧可见加104后续可见，另1原生 MESH 全程隐藏属于正确排除。

首页采用参考相机投影到连续 relief 深度网格，叠加实体圆柱轴杆、曲面卷纸与厚度、桌裙和主要器物。它不是独立完整建模的全房间，也不是完整贴图重画；此工程取舍由 Agent 为保持参考构图作出，不能描述为用户确认了完全独立建模。观察角度受限，微相机运动显示真实深度；不支持大视角绕行。参考 SHA 为5ddde6154a57aa96bec01bdcb2f2e85bf0599ff28b01439988355768d1639f27，题签局部底板补绘，四卷文字由可读 HTML 按钮重做。原始标题不重复绘制。

首页 compileAsync 后还要完成实际首绘才发 ready；Three.js 首次使用报告的 shader 链接失败会停止 RAF、禁用入口、显示重新陈设。独立加载画境保留双面纸张绕轴的闭合到展开，前台至少4000ms；画境与目标世界各自准备完成并取得首帧后才进入，失败、重试、取消旧任务和重复选择保持明确状态。

加载卷面的四份cover取自新版WebGL源进度0的实际画心截图，关闭环境、隐藏HTML正文后直接转WebP，不重绘或换构图；来源SHA及四份源身份记录在reports/new-scrolls/cover-provenance.json。它们替代旧paintings-atlas并按原比例装裱，纸面保留实际暖光材质，不宣称逐像素同色；实际衔接以本轮截图另行验收。

25段 DOCX 正文按6／6／6／7逐字保留，Agent短标题只作导航，不改正文。实际新源节点映射到短题跋，楷体使用本地霞鹜文楷子集；CSS渐显650ms，reduce180ms。NarrativeSpace 从真实绘制像素的候选区域估计纸白与边缘密度，选择较安静位置；启发式不能代替主体避让的逐景审阅。此前仅密集画面加淡底，2026-10-23按用户新要求改为所有HTML文字始终有可调底板，四卷滚轮参数独立公开；采样改为小图异步回读。实现与取舍见[游观设置与性能](../知识/游观设置与性能.md)。到末尾退出正文、停止轻动，显示大卷名、末句与一次落印。

新版轻动仅使用已逐图审阅的独立层及来自新源的单瓣，不移动人物、建筑或组合画层。追加对象使用同一流式队列和销毁周期。配乐为脚本创作的76.8秒原创五声音阶曲与合成古筝意境拨弦音色，非真人录音；用户点击启用，音量可调，隐藏或离开时暂停，无语音朗读。
