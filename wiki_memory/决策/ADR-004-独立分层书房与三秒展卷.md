# ADR-004 独立分层书房与三秒展卷

## 用户选择与替代范围

用户提供新视觉母版《国色长卷：牡丹雅韵四卷展》，明确替代旧版整图不变加热区的呈现要求。原始参考继续保存，但实际首页必须由独立景物、真实题签与深度运动组成。四卷内容、顺序、相机与功能不重写。

## 已采用实现

Agent在授权范围使用imagegen制作远景园林、透明窗框与陈设、空案台、四卷、前景与书法六幅素材；四卷及前景再以代码裁区作为独立平面，合计九个深度平面。透明窗洞与完整远景、空桌补绘避免视差露洞或原卷重复。运行素材编码为WebP，原PNG、原始参考、准确提示词和透明边界记录均保留。

原生button题签呈现四个真实卷名，绢纸、古铜边、厚度、接触阴影、箭头与流苏独立组成；hover/focus抬起、按下下压，画作主体也可点击。绘画的裁区同时约束真实指针区域，避免透明矩形截获相邻卷。按钮层级高于近景花枝，不遮文字。

一个合成时钟向各景深平面写CSS位移，只有局部景物在静置时缓慢呼吸，不反复缩放整张图冒充空间。环境开关、隐藏页面与减少动态停止环境时钟和循环。手机重取中景、四卷两列，不依赖hover。

每次点击、直达、刷新、历史和重试均从苏醒开始，正常基础仪式6秒，其中SCROLL_LOADING至少可见3000ms。减少动态用柔和渐显、禁用大镜头，但三秒门槛不缩短；后台时间不计入。资源更慢则继续等待。清单、当前和邻近视野纹理、画材解码及真实WebGL首帧门控保留，不把时间当下载进度。返回仍停播收卷、恢复选择。

## 证据与限制

分层、原生按钮状态、跨透明边缘命中、失败素材的真实DOM恢复、四种窗口及四卷真实进入与返回见reports/study-layered。三秒与所有导航路径计时见reports/study/validation-timing.json。既有scene.json、canonical和Blender未改。验证不等于实体手机、跨浏览器、物理纸张或持续60FPS测量。
