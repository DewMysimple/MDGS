# 当前状态

## 项目目标与阶段

《国色长卷·数字牡丹赋》React/TS/Vite/Three.js电脑端交互手卷，内置四卷Blender源画面、首页、启卷、遇景、45短章、声景和花笺。最新按新版Blender替换第三卷首饰罐盒组合并核对播放；此前为四卷各新增两款可选花笺画面，保留原有四种心意和钤印保存流程；此前移除首页花影交互及其指引，并将四卷画中有遇题笺分别放到对应热点附近；保留首页、入卷及卷末首次观卷指引与重看入口；保留四卷素材核对与首卷花车画面补全；保留录屏卡顿修复、播放时钟和资源预加载优化；保留720p/1080p/2K画质与30/60绘制上限；原网页风格、布局、源运镜和指定入场保留。

本轮起点为本地main `c507390`，领先origin/main一个提交、工作树干净；用户本轮要求将当前版本同步到GitHub。接续时重新检查Git，不把历史远端或本页记载当当前revision。历史迭代见日志索引。

## 关键入口与运行命令

`npm ci/dev/build/preview`；`npm run export:exhibition`生成独立HTTP展示包；`npm run export:desktop -- --output <新目录>`生成Windows x64便携EXE及ZIP，内置Electron45/Chromium/Node24、字体、声音及运行资源，无需Blender，断网可用。打包脚本核对源快照、原图原字节、ZIP CRC及实际解压SHA，不等于交互验收。便携程序设置写入当前Windows用户应用数据目录。5173属于其他项目勿杀；本轮临时预览服务已关闭。

相关入口：App/ScrollViewport负责React设置和渲染器连接；viewerSettings/ViewerSettingsPanel管理原生控件与v2存储；renderQuality/FramePacer集中质量预算和节拍；SceneRenderer/SourcePostProcessing/SourceLighting/SourceMaterial负责实际画卷；PeonyBloomSurface负责首页花影。原资源由sourceEdition及每卷manifest关联。

历史验收记录不代表当前版本的动态验收。

## 约束与已确认选择

- 用户要求保留网页艺术风格、整体布局和交互；原始blend、源图片、作者几何/相机/形变、25段原文受保护，不保存修改四份packed blend。原图、数值程序场在交付中原字节复制；本轮低档仅在运行内存缩小颜色图、减少采样。
- 用户要求720p/1080p/2K和30/60帧选项及观看效果、性能备注。Agent选择默认720p/30，旧v2设置缺字段时补此默认；其他旧值保留。两处设置共用，选择立即生效、本机持久化，恢复默认也回最低档。帧数是画卷绘制上限，不保证每设备达到，也不等同浏览器合成/显示器刷新率。
- 三档真实画布/离屏像素上限分别1280×720、1920×1080、2560×1440；宽屏/竖屏保比例。Film4/16/36、DOF8/16/32、SUN4/8/16、AREA8/16/32、shadow1024/1536/2048。颜色图限边1024/2048/原图；DataTexture、Non-Color数据保留。切档不重建renderer，候选完整上传再替换。
- 用户指定首卷 `主体 · 03_中央花车巡游与曲水` 工作视图可见但全程hide_render，按用户截图作为单对象例外恢复原几何/材质/无损图；不添加入场效果，不改blend，原render隐藏事实保留在审计。
- 首卷精确源SHA中审核的120个镜头外驻留对象改由视锥裁剪，指定11条材质入场轨保留；未知源和未审核显隐不改。阴影解析梯度、光栅误差界限、稳定拟合和资源就绪门控保留，误差随实际阴影图尺寸计算。资源等待不计入自动时间，慢设备最多一个源帧推进，可能延长总时长。
- 四卷每侧默认8%等宽留白，公开0—18%/0.5%步进；原画比例和竖向取景不改。滚轮.5%每100px/180ms；底板80%/12px/0/0；候卷至少4秒且需资源及真实首帧。CSS文字与锚点使用原尺寸，画质不缩小字体。
- 全屏目标为画轴/锦边/画心区域；Electron通过preload IPC协同窗口全屏，画面内可退出。首卷画面在进度.99封顶，交互进度仍到100%，避免源末帧拉坏构图；全屏隐藏卷末题笺。
- 原始牡丹/牡丹2.0/DOCX、参考附件、raw trace/JPEG/PCM、制作TTF、缓存、机器配置与凭据不提交。历史许可、来源和艺术选择在ADR008等页；当代短章、原创合成声景不冒称原文或真人唐乐。Film/DOF为数值近似，不宣称完整EEVEE等价。
