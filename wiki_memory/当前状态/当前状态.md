# 当前状态

## 项目目标与阶段

《国色长卷·数字牡丹赋》React/TypeScript/Vite/Three.js数字手卷。活动源为 `peony-2026-10-21`；本轮四卷性能/滚动、导航设置、用户指定的微透明文字底已实现并验收，交付提交包含本页，最终HEAD及远程同步以Git实际核对为准。开始核对时为main、HEAD `cd5bd9c`、upstream origin/main，工作树干净；本轮未部署。

## 关键入口与运行命令

`npm ci`、`npm run dev` 或 runStart.cmd启动；`npm run build`、`npm run preview`生产检查。网页不依赖Blender/Python或外部字体；相对BASE_URL支持HTTP子目录。

sourceEdition/prepareScene保留新版作者时间、矩阵、相机、显隐及所有节点。StudyRoomRenderer/StudyHome是参考投影relief首页；useStudyJourney/ScrollUnfurlScene保持前台至少4000ms闭卷展开及真实资源/首帧联合门控。具体源边界见ADR-006。

本轮入口：viewerSettings.ts校验与浏览器存储；ViewerSettingsPanel.tsx设置；useScrollController/scrollMotion/ScrollViewport负责按时间输入；SceneRenderer/NarrativeSpace负责按需绘制、流式纹理及小图异步留白采样；text-backplates/narrative-calligraphy/viewer-settings CSS负责文字纸底及排版。

验证命令：npm test、npm run validate:assets、npm run test:scroll-input、npm run test:render-performance、npm run test:viewer-settings、npm run test:new-runtime、npm run test:new-journey。浏览器测试需Playwright/Chromium，可用MDGS_PLAYWRIGHT_MODULE、MDGS_TEST_BROWSER、MDGS_PREVIEW_URL指定本机环境；不把这些路径放进产品配置。

## 约束与已确认选择

每轮修改验证、提交并推送实际upstream，无需普通Git再授权；失败保留本地提交并报告真实障碍。原始牡丹输入、原DOCX/参考图、缓存和凭据不提交；本轮不修改Blender、画面素材、作者时间线及原文。reports图像沿既有Git LFS规则交付。只读任务不写记忆。

Agent本轮采用：四卷独立默认0.5%/100 CSS px（旧1.6%）、180ms指数跟随；速度0.1—2%、平滑60—500ms。行/页输入归一，单事件160px限幅、连续积压6%上限、反向清旧方向积压；拖拽惯性按时间积分。参数即时生效而不重建画卷，localStorage保存，支持恢复默认。

用户2026-10-23明确要保留参考图的微透明纸底，拒绝偏实色圆角卡片。所有HTML阅读文字按组提供轻透纸底，正文沿用原渐变和柔边，文字自身不淡化。默认纸底峰值不透明80%、留白12px、圆角0、边框浓度0，参数公开；使用v2参数键以免读取未交付v1草案。正文按实际区域和留白分段；保留原字与650ms渐显（reduce180ms）。原画烘焙文字/印记不改素材。留白分析是启发式，不保证主体完全避让。
