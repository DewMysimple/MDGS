## 关键入口与运行命令

正常使用npm ci、npm run dev或runStart.cmd；npm run build / npm run preview检查生产版本。网页无需Blender/Python或外部字体。BASE_URL支持HTTP子目录。

sourceEdition.ts把四世界指向public/assets/new-scrolls/chapter-1..4；SceneRenderer保留世界矩阵、完整相机、源动画/可见性与流式纹理。prepareScene对新版保留作者时间0..1，不按距离重排或套旧结束帧；距离映射仅历史版。StudyRoomRenderer与StudyHome负责参考投影首页和HTML题签；useStudyJourney、ScrollUnfurlScene负责闭卷加载。

newNarrative.ts、narrativeTrack.ts、NarrativeCalligraphy负责25段正文与CSS渐显；NarrativeSpace读实际绘制像素估计留白。newMotionProfiles与NewScrollAtmosphere负责少量独立层轻动，AudioController播放本地原创合成古筝意境配乐。

新版检查：node scripts/validate-new-scroll-assets.mjs（MDGS_PYTHON需Pillow）、validate-new-narrative.mjs、validate-new-motion.mjs、validate-projection-home.mjs；另npm test、npm run validate:assets、npm run build按当前代码运行。原生只读复核：blender --background --disable-autoexec --python scripts/validate-new-scroll-native.py。完整浏览器脚本需Playwright/Chromium，可用MDGS_PLAYWRIGHT_MODULE / MDGS_TEST_BROWSER / MDGS_PREVIEW_URL指定，不入产品配置。
