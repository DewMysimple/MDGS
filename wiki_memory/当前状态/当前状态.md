正常npm ci、npm run dev或runStart.cmd；npm run build / npm run preview检查生产。网页无需Blender/Python或外部字体，BASE_URL支持HTTP子目录。

sourceEdition.ts指向public/assets/new-scrolls/chapter-1..4；prepareScene对新源保留作者时间0..1，原相机、矩阵、显隐与材质scalar同钟推进，不按相机距离压掉静止景。SceneRenderer使用Worker清单解析、构造分片、预分解矩阵、异步纹理解码、每帧单次上传和方向预取；NarrativeSpace在停滑后用低分辨率异步GPU读回并缓存。SourceMaterialEffects译制源材质uniform图。StudyRoomRenderer/StudyHome负责参考投影首页与真实HTML题签，useStudyJourney/ScrollUnfurlScene负责前台至少四秒闭卷展开。
