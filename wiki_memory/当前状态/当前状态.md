# 当前状态

## 项目目标与阶段

《国色芳华》是基于用户四个 Blender 2.5D 场景的牡丹文化数字手卷。四章节、真实场景游观和桌面装裱 UI 已实现；最新视觉基准为传统手卷概念图，验收尺寸 1440×900、1680×945。旧版近满屏约77%的布局已经被本次装裱形制替代，不能照旧报告回退。来源：`reports/handscroll-ui-review.md`、`src/styles/exhibition-theme.css`。

当前交付包含源码、完整网页资产、导出脚本、验证报告和本记忆；正式网站部署不在已完成范围。本次首次 Git 交付已完成：main 跟踪 origin/main，首个源码与记忆提交 `8b826d379bb08bc2bc954973dc503e13c18b89aa` 已通过远程 ls-remote 核实。该 SHA 是交付基准，后续收尾记忆提交及当前状态以 `git status -sb`、`git log -1` 和远程引用为准。

## 关键入口与运行命令

技术栈为 React + TypeScript strict + Vite + Three.js；精确依赖以 `package-lock.json` 为准。`src/App.tsx` 组织四卷导航、真实分镜进度和控制；`src/data/chapters.ts` 管策划正文，`sceneOptions.ts` 管阅读路径结束帧，`annotations.ts` 管卷内题字；共用视觉参数在 `src/styles/exhibition-theme.css`。

在项目根运行 `npm ci` 安装锁定依赖；`npm run dev` 启动 http://localhost:5173/ （固定端口，冲突即失败）；`npm run build` 生产构建，`npm run preview` 本地检查构建。运行网页只依赖仓库中的 public 资产，重导出才需要外部 Blender 文件。模块关系见 [[知识/手卷界面与交互.md]]、[[知识/场景资产与导出.md]]。
