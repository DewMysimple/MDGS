## 关键入口与运行命令

`npm ci`、`npm run dev` 或 runStart.cmd启动；`npm run build`、`npm run preview`生产检查。网页不依赖Blender/Python或外部字体，支持BASE_URL子目录。

`sourceEdition.ts` 指向四份当前scene.json；SceneRenderer恢复源世界坐标、每整数帧相机/物体动画/显隐和25个形态键，统一流式纹理及程序字段队列。SourceMaterial执行原节点闭包与实际参数轨；SourceNoise3D直接求值高频纸噪声，其余静态程序场由原生采样。SourceLighting处理世界、SUN/AREA和透明阴影；SourcePostProcessing在线性HDR重建源Film采样、景深及首卷原生AOV Glare贡献。

sourceClock/useScrollController按 `(end-start)*fpsBase/fps` 与真实墙钟自动播放，低刷新率不减慢原片。手动游观继续按上游可调平滑。完整源视场按源比例居中显示，窄屏留边，不裁作者构图。原生版停止附加花瓣/环境图层和鼠标镜头偏移，源动画仍随时间推进。

验证入口：`npm test`、`npm run validate:assets`、`npm run validate:new-assets`、`npm run test:peony2-clock`、`npm run test:peony2-narrative`、`npm run test:render-performance`、`npm run test:peony2-fidelity`、`npm run test:peony2-runtime`、`npm run test:peony2-journey`。浏览器需MDGS_PLAYWRIGHT_MODULE、MDGS_TEST_BROWSER，图像检验需MDGS_PYTHON，均不写产品本机配置。
