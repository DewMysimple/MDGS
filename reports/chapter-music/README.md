# 四卷配乐替换与播放核对

## 输入与实现

2026-11-02 用户提供 `E:/动效网页/牡丹音频/` 中一、二、三、四四首 MP3，要求分别作为四卷配乐，实测并只保留本地。四文件按字节原样复制为 `public/audio/chapter-1.mp3` 至 `chapter-4.mp3`；各文件SHA、浏览器完整解码时长、声道、峰值和RMS见 `source-analysis.json`。未更改原始文件或对其重新编码。

首页使用第一卷音乐；切卷根据当前卷选择对应曲目，音频解码在需要时发生，旧曲与新曲约0.8秒淡出淡入。每次只缓存一首完整解码音频，切换期间短暂持有旧声源，避免四曲常驻内存。音乐默认关闭，继续使用原有启声、音量、阅读时降低、隐藏页面暂停、返回恢复、交互提示音和重试。每首音频循环前后仅在内存中施加40毫秒柔化，减少循环接缝的突变；音源磁盘文件不变。界面及打包文案改为画卷配乐，避免将用户提供的音频标为旧原创曲。

## 实测

Windows、打包后的 `dist-desktop/win-unpacked/数字牡丹赋.exe`，隔离配置、`mdgs://`本地协议，通过 `node scripts/validate-chapter-music.mjs <EXE> --packaged` 实际启声并游览四卷。检查18项：四卷对应资源与非静音输出、各卷切换的信号、每曲强制跳至末尾后的循环、主输出连续PCM峰值和相邻采样、音量归零与恢复、关闭重启、模拟隐藏恢复、返回首页、模拟资源503及重试；全部通过，四卷循环采样均无满刻度削波及超过0.9的相邻采样跳变。完整原文件通过浏览器 `decodeAudioData` 全长度解码，未发现满刻度削波。

这是一台Windows设备上的真实音频图输出与数字信号检查；没有通过人的听觉逐曲听完整段，不能保证任何音箱、驱动或原素材中的所有主观杂音均不存在。四个原文件平均响度不同，第三卷相对较轻；未做动态压缩或整体响度改写。相关输出见 `playback-validation.json`。
