# 第一卷保留素材的UV裁边复核

只读扫描当前未替换、未修边、未退役且纹理裁决为“保留”的199个实例，逐三角形把UV覆盖与原图alpha比较。实际查看了候选诊断图、原WebP、第七景及第十四景网页截图；没有改原图、场景或canonical。

本轮明确三项背景硬口：

| 实例 | 原图 | 被几何丢弃的可见alpha | 视觉结论 |
| --- | --- | --- | --- |
| 07_2-山水人群.001 | C1-T048 | 81.7% | 山水横向切成前置碎片，第七景左下有明显水平接边 |
| 14_背景01_女帝身后背景_补全.001 | C1-T094 | 66.6% | 圆光云山仅留底部片段，云气从内部截断 |
| 14_背景02_右上与右下书页后背景_组合.001 | C1-T095 | 55.9% | 云纸网格出现高不透明L形直角裁口 |

三张原图均已打开查看，没有烘焙正文，原始颜料轮廓完整。各自同纹理主实例仍在，建议退役额外的`.001`裁片并保留主实例，再检查已有墨气桥与留白。若必须保留遮挡，应恢复完整轮廓后重新排布；整张原图自动复制回每个辅助裁片会增加重复山水、圆光或云纸。

两份C1-T093红绸漏掉约18.1%颜料，但不是本轮背景硬口三项。其他若干UV范围未到1的对象主要裁掉透明安全区，不能仅凭UV min/max批量修改。
