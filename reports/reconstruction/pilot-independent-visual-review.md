核实日期：2026-10-20。查看首卷 overview、05/08/10/14 原尺寸画面及 before 对比，并以原 `scene.json` 的 UV 三角形覆盖实际纹理 alpha 做诊断。审查期间没有覆盖任何原图或原 `.blend`；发现问题后按主任务分配仅调整派生工具、生成必要修复资产并重存首卷。

## 发现、原因与处理结果

1. **第8景上半山水阶梯口是基线原有几何缺口。** `C1-T052 / c1-t-2a10c80ab45dd69b`、对象 `08_01_上方山水城景` 原网格为避开烘焙说明文字，删去阶梯状 UV 区域，挖掉原图有效像素17.98%。before 与最初 pilot 形状相同，并非补全宫阙放大造成。原PNG为 `source/牡丹/素材/场景图层素材/牡丹场景素材元素/一/1-8/01_上方山水城景.png`。现在使用保留山水/城景、清除烘焙文字的 T052 修复图和完整 UV 平面，最新 Stop08 已恢复自然云山轮廓。
2. **四张补全图最初仍被旧裁片网格截断。** 仅放大源网格不能消除源 UV 缺面；`uv-coverage.json` 与逐图诊断记录了像素确实丢失。这纠正了此前“几何/材质重开一致”被误当作“补全主体完整”的宽泛理解：前者只证明保存与重开一致，不能证明美术完整。现为每个 replacement 使用同一份原导出样本，按居中协方差求 `P=a+b*u+c*v`，生成 UV `(0,0)(1,0)(1,1)(0,1)` 四角，并适配透明 gutter 和内容宽高比。原对象矩阵与父子关系保持；轻微原法向起伏被明确归入允许的派生几何变化。
3. **Gap04 园丁底边是纸底深度遮挡。** 对象 `05_03_园丁与牡丹`、`C1-T036 / c1-t-0a5d34c4eb6cffe6` 的 PNG 包含完整蹲姿衣摆和自然草叶土边，源 UV 有效像素损失0%，无需再生成图。网页实测只取消声明的纸底 depthWrite 即恢复完整下沿；遮挡物是 `长卷_连续绢本地形`，材质 `绢本_纤维与浅墨`。派生 Blender 只隐藏水平纸底的 render，保留该对象、矩阵和原材质/几何，后方 `长卷_统一留白天幕` 继续渲染，不改变 World。
4. **9个原修边对象未发生 UV 丢主体，但有两张源图本身不完整。** 逐项覆盖损失均为0%，没有需要隐藏的烘焙叙述长文。T067 的书本墨迹属于器物细节。T059 原官员群下摆/足部和 T067 原书案/前景衣摆欠缺，因此通过内置 image_gen 做局部扩绘；人物身份、姿态、书案与画法保留。原图不覆盖，raw/生产PNG/WebP与完整提示词均已保存。不能把羽化或“0% UV损失”当作完整主体的证明。
