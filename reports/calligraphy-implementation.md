# 卷内竖排题字实现

- `src/data/annotations.ts` 管理四卷题字内容、诗句/短句、介绍、字体、字号、世界位置与宽高、印章位置、所属阅读分镜、显示区间。
- 标题及介绍读取既有 `chapters.ts`；二、三卷的短句来自现有展陈编辑文案，不冒充历史诗文。第一、四卷诗句来自用户提供文字。
- `src/scene/CalligraphyLayer.ts` 用 CSS3DObject 和真实 HTML 的 h2、p 排版，使用 `writing-mode:vertical-rl`、`text-orientation:upright`，列序从右至左。
- 题字平面以指定阅读节点的原相机局部坐标定义固定世界位置；游观时用当前原相机投影，与画卷内容共同移动。没有修改摄像机位置、路线、FOV 或原始 scene.json。
- 叠层和全部后代均为 `pointer-events:none`，不会截获滚轮、拖拽等操作；原视口负责裁切，章节销毁时移除 DOM。
- 印章使用现代中性装饰文字“牡丹”，不赋予历史印文身份；可在配置中通过 `seal.assetUrl` 换成用户提供素材。

## 安全显示策略

| 卷 | 开启 | 空间依据 |
|---|---|---|
| 神都花事 | 否，完整配置保留 | 卷首宫苑、人物、山石构图密集，避免加字遮盖原画 |
| 花入万家 | 是，0–5.5% | 原首景左侧宣纸余白，邻景出现前淡出 |
| 锦绣花意 | 是，0–4.5% | 沿用原实现经核对的左侧安全题字区 |
| 国色倾城 | 否，完整配置保留 | 原图自带横排策划正文，保留并避免重复标题 |

题字并非永久固定的右侧面板；没有给其他分镜强加统一的“左画右文”结构。若后续需要各卷更多题字，可在确认真实场景留白后独立调整配置。

## 验证

- `npm run build` 通过，新增 CSS3DRenderer 来自现有 three 包，没有新增依赖。
- 最终布局中的像素位置及移动行为由主任务浏览器验收记录补充。
