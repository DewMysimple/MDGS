# 四卷游观与微透明纸底

2026-10-23，针对四卷进入后不稳、滚轮跨度过大和文字缺底的问题实现。用户明确要求保留原有微透明纸绢质感；默认不采用实色圆角卡片。

正文使用渐变纸色和上下柔边，画面能透出，透明度只作用于纸底，文字保持清晰。实际生产截图：[正文局部](micro-transparent-detail.png)、[完整画面](micro-transparent-desktop.png)。首页实体题签内层仍以清洁纸材遮住原图烘焙卷名，防止与HTML字重影；其上叠微透明调色层。

| 设置 | 默认 | 范围 |
| --- | --- | --- |
| 四卷独立滚轮速度 | 每100 CSS px推进全卷0.5% | 0.1—2% |
| 四卷独立平滑时间 | 180ms指数跟随常数 | 60—500ms |
| 纸底颜色 | 米白 | 五种浅纸色 |
| 纸底峰值不透明度 | 80%，边缘更淡 | 20—100% |
| 留白 | 12px | 4—24px |
| 圆角 / 边框浓度 | 0px / 0% | 0—20px / 0—60% |

首页和卷内导航均可打开设置，即时生效并保存于浏览器，可恢复默认。v2设置键隔离本轮未交付的实色草案；正文段落容量随留白与画心尺寸变化，原文不变。设置截图中的大留白、圆角或边框是参数验收用自定义值，不代表默认样式。

滚轮原先100px约推进1.6%，目前默认0.5%；统一像素/行/页输入、限制单事件160px与连续积压6%，反向及时切换目标。缓动和拖拽惯性按真实时间计算；闲置不空转，后台停止自动展卷。大跨度时间轴跳转仍可使用。

正文避让不再同步读完整画布；使用保持比例、最多256×192的离屏缩略图和异步GPU回读，停止游观180ms后更新。临近源显隐图层预取占至多一个后台槽，当前画面优先；不提前显示源隐藏物体。复用源动画结果、预取相机并减少静态矩阵遍历。shader失败与迟到纹理回调不会误清错误或解锁首帧。
