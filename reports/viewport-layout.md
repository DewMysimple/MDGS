# 桌面画卷占比调整

依据用户标注截图（1897×1000），画布改为导航下方的近满宽区域。独立标题行、侧边装饰和底部页脚不再占据画布空间，标题仍保留在导航、文化解读和无障碍标题中。

浏览器实测：

| 窗口 | 画布位置 | 画布尺寸 | 底部控制起点 |
|---|---|---|---|
| 1897×1000 | x5，y124 | 1887×767 | y891 |
| 1440×900 | x5，y111.59 | 1430×690.31 | y801.91 |
| 1280×800 | x5，y99.19 | 1270×602.81 | y702 |

四卷沿用同一画布布局；实际检查四卷卷首、第二卷卷末与文化抽屉。Three.js 通过 ResizeObserver 更新真实渲染尺寸与相机宽高比，没有使用 CSS 拉伸。另修复网格布局在窗口缩小时受旧 canvas 内在宽度撑开的情况。

`npm run build` 通过。截图：`screenshots/viewport-match-1897.png`；尺寸原始记录：`validation-viewport.json`。本次仅调整桌面端。
