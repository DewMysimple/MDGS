# 第三卷专项整改方案

先审查后实施。具体问题见 `audit-visual.md` 与 `technical-audit.md`，可编辑文案候选见 `typography-proposal.md`。

1. 九个主景先内收下移，维持中下部重心。删除第三景截边高屏风、第七景悬空宫苑、第八景重复上组；保留人物与器用主叙事。原相机、世界矩阵、动画、源文件不改，局部载体仿射是本轮明确派生例外。
2. 婚嫁幕台、迎亲远景、雪巷三处真截口分别定向补绘透明新图，原图保留。自然视口边缘不强制塞回画内。
3. 八个过渡留白与第七至九景加入窄幅竖题与两短列；第三、四、六景既有横题转竖排。第二景不另加正文。按每帧一组的范围与淡入淡出控制密度，顶部不堆字。
4. 地坪/器物只在实际接触问题处调整；镜台垂布已完整，优先修接地与白缝。
5. 同一清单驱动网页与新Blender副本：文字独立可编辑，原长文与网页一致做派生隐藏；竖排字体打包、真实frame控制题签显隐。
6. 完整重拍九停驻/八中点/十六四分点，并做三种窗口与正反交互、真实Blender预览和独立重开；用真实同进度图片交付前后对比。

首轮数值为候选，不以结构测试代替逐帧美术验收。完整机器可读字段与验收要求见 `plan.json`。

## 逐帧复核后的实际执行

- 主景按下沿内收：第1/2/3/4/6/7/8景0.82，第5景0.74，第9景0.78；额外工坊地面向镜台右足内收和上接，闭合窄纸沟。原世界矩阵与相机/动画保留，局部载体几何是明确派生例外。
- 文字共15组：8中点与第3/4/5/6/7/8/9停驻。原三横题重排，第5景加入灯彩迎新；只第7景配安居小印，卷首继续原开题。文案均原创展陈短句，不冒称古诗史引。
- 三处定向透明补绘分别修婚嫁幕台两端、迎亲右端、雪街左端；第3景高大截边屏风退役。未增加新大场景填满白纸。
- 本轮额外退役31源辅助/旁景：3高背景、2游离重复花枝、1有硬顶口的重复山水，以及经真实同帧显隐确认会穿过锦布的25辅助细线。真正第9景城景仍保留，原文件只读。
- 锦架gap02围绕脚部再收6%，让文字下端与锦布分开；足点保留，原地坪维持。
- 窄画心根据真实字带尺寸留纸面题字带，原视点等比收入下方。字号保持正文14/标题18px以上；短窄窗也以内容尺寸判断，未规定固定窗口尺寸。Blender保存宽屏世界锚点，网页小窗响应排版另作明确验证。
